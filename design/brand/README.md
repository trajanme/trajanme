# daywizz

日本各地の魅力に光を当て、地域がにぎわい続ける仕組みをつくる。daywizzのスライド、Webサイト、LP、名刺はすべてこのシステムで作ります。テーマは「土地と灯り」。森と生成りの落ち着いた地に、灯りの橙をひとつだけ灯します。

## MVV

- **Mission**: 日本各地の魅力に光を当て、地域がにぎわい続ける仕組みをつくる。
- **Vision**: 訪れる人が土地の良さを知り、暮らす人が元気に楽しみ、そこで育つ子がAI時代を力強く生きる日本。
- **Values**
  - 地域が主役:主役は土地とそこに暮らす人。daywizzは光を当てる側に徹する。
  - 楽しめる体から:歩く・巡る力を毎日の習慣で育て、地域を楽しみ尽くせる人を増やす。
  - どこで育っても:都市部でなくても、子どもの発想力と学ぶ力を伸ばせる環境を届ける。
  - 小さく、速く、届く形で:予算や人手の少ない地域でも使える規模と価格で届ける。
  - 仕組みまで変える:一度きりで終わらせず、ITと業務の仕組みに落として続く形にする。
- **強み**: AIで少人数・低コストの支援ができる/コンサルで培ったIT・業務変革への深い理解
- **タグライン**: 地域に、ちいさな魔法を。(英: A little magic for every corner of Japan.)

3つの柱は「地域の魅力を届ける(訪れる人)」「楽しめる体をつくる(暮らす人/PawSteps)」「地域で育つ力を伸ばす(育つ子/Picolle)」です。

## 言葉づかい

- 主語は地域と人。daywizzは控えめに。「daywizzが変える」ではなく「地域が動き出す」。
- です・ます調。短い文で、専門用語はかみ砕く。支援先向けの資料でも、カタカナのビジネス語は最小限にする。
- 誇張しない。「革命的」「圧倒的」、感嘆符、絵文字は使わない。数字は出典のあるものだけ。
- 英語は直訳でなく、短く平易に。日英を並べる時は日本語を先に置く。

## 色

- 地色は `kinari`、浮かせる面は `surface`。
- ブランドの主役は `forest`。スライド表紙や見出し帯の塗りに使い、上の文字は `on-forest`。
- `akari` は1画面に1か所だけ。いちばん押してほしいボタンか、いちばん伝えたい数字の塗り。上の文字は `sumi`。文字を橙にしたい時は `akari-text`。
- 文字は `sumi`、補足は `ink-muted`。
- `wakaba` は地図、図表、タグの地。色だけで意味を区別せず、明るさの差かラベルを添える。

## 文字

- 書体は Zen Kaku Gothic Antique の1書体のみ(Google Fonts、商用可)。骨格はモダンなゴシックで、かなに古典的な形が残るのが和の手がかりです。欧文も同じ書体で組みます。
- 太さは 400(本文)と 700(見出し)。500 はキャプションのみ。
- 段階は display 56 / h1 40 / h2 28 / h3 20 / body 16 / small 14 / caption 12(px)。スライドは display と h1、Webは h1〜body を主に使う。
- 和文の行間は広め(本文 1.75)。見出しは詰めすぎない。

## ロゴ

- マークは「丘と星の灯り」。2つの重なる丘(土地・地域)の上に、4つのひし形でできた星(地域に当てる光、日々の小さな魔法、旅の道しるべ)が灯ります。丘は `forest`、星は `akari`。
- ロゴはマーク単体(`daywizz-mark.svg`)、横組み(`daywizz-logo.svg`)、タグライン付き横組み(`daywizz-logo-tagline.svg`)の3つが基本形。それぞれ白1色版(`-white`)があり、`forest` の塗りや写真の上では白版を使う。
- 背景込みのコントラスト版として、森の正方形に白マークのアイコン(`daywizz-icon.svg`)と、森の地に白の横組み(`-forest`)がある。
- ワードマークは「daywizz」を Zen Kaku Gothic Antique Bold で組み、アウトライン化したもの。色は `sumi`。
- マークの周りには、星の高さ以上の余白をとる。変形、回転、影、色の入れ替え(丘を橙、星を緑など)はしない。

## 媒体ごとの使い方

- **スライド(16:9)**: 表紙は `forest` 塗りに display。本文ページは `kinari` 地に h1 と body。外周の余白は `space-10`。強調の数字だけ `akari`。
- **Web・LP**: `kinari` 地、セクション間 `space-16`、カードは `surface` + `line` の縁 + `radius-md`。主ボタンは `akari` 塗りの `radius-pill`、高さ44px以上。
- **名刺(91×55mm)**: `surface` 地、左上に横組みロゴ、下に氏名(h3相当)と肩書き・URL(caption相当)。裏面は `forest` 塗りにマークの白版とタグライン。

## 部品

Web・LP用の部品は `components/bundle.js` に `window.daywizz` としてまとめてあり、React 18 を前提にしています。スタイルは `components/bundle.css` のクラス(`dw-` から始まる)なので、Reactを使わないページでも同じクラス名で組めます。

- `Button`:primary(灯り・1画面1つ)/ secondary(森)/ quiet(線)
- `Tag`:分類を1〜2語で
- `Card`:柱・事例・アプリの紹介
- `SectionBand`:章やセクションの始まりの森の帯
- `Stat`:大きな数字1つで成果を伝える

## 使わないもの

グラデーション、影の重ね、絵文字、写真への色かぶせ、橙の多用。
